## Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

### Project Overview
This project automates the **Standard Laptop procurement process** in ServiceNow using **Flow Designer**. The workflow creates a catalog task after a laptop request is approved and assigns it to the **Hardware** team.

### Objectives
- Automate standard laptop requests.
- Reduce manual work and processing delays.
- Automatically create configuration tasks.
- Assign tasks to the Hardware team.
- Improve IT procurement efficiency. Streamlining IT Procurement\_ Au…

### Workflow
1. Create the **Standard Laptop Task** flow.
2. Use **Service Catalog** as the trigger.
3. Create a **Catalog Task** automatically.
4. Set the short description to **“Laptop need to Configured.”**
5. Assign the task to the **Hardware** group.
6. Set the approval status to **Approved**.
7. Assign the flow to the **Standard Laptop** catalog item.
8. Place and approve a laptop request.
9. Verify the generated Catalog Task. Streamlining IT Procurement\_ Au…
